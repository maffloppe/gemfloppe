## Xray-core

- Источник: https://github.com/XTLS/Xray-core
- Лицензия: Mozilla Public License 2.0 — https://www.mozilla.org/MPL/2.0/
- Что используется: ядро туннеля, поставляется отдельной библиотекой без изменений

Исходный код Xray-core доступен по ссылке выше. Изменения в него не вносились, поэтому раскрывать нужно только сам проект, а не код приложения.

## libv2ray

- Источник: https://github.com/2dust/AndroidLibXrayLite
- Лицензия: Mozilla Public License 2.0 — https://www.mozilla.org/MPL/2.0/
- Что используется: AAR-обёртка для запуска ядра на Android, без изменений

- Источник: https://rsms.me/inter/

## Как это соблюдается

Тексты лицензий и ссылки на источники доступны в приложении: «О приложении» → «Лицензии». Этот файл лежит в репозитории рядом с README.
