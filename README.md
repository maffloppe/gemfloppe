# Gemfloppe

Клиент для Android: DNS и VPN. С которым разберется даже тот кто впервые видит телефон!

## Что умеет

- **VPN-режим** VPN на основе ядра Xray
- **DNS-режим** Меняется только DNS
- **Раздельный DNS** Выбранные сервисы идут через DNS, остальное - через VPN. Список сервисов в приложении, 44 цели в категориях: нейросети, видео, соцсети, общение, музыка, игры, работа
- **Обратный режим** Через VPN идут только выбранные сайты, всё остальное напрямую
- **Автовыбор сервера** Подключение ко всем серверам подписки одним конфигом: балансировщик сам выбирает лучший сервер, переключение без разрыва и без вашей помощи!
- **Автовыбор DNS** При подключении проверяется, подменяет ли адреса для выбранных сервисов, среди подходящих берётся самый быстрый
- **Проверка DNS** Если выбранный резолвер не работает для сервиса, выбранного для пинга, приложение предупреждает до подключения
- **Протоколы DNS** IPv4, DoH, DoT на каждый DNS отдельно
- **Пинг** Заранее добавлены сервисы для проверки пинга, в отличие от других клиентов
- **Помошник серверу** Если сервер перестал отвечать, приложение предлагает переключиться, но не делает это само
- **Помощь** Десять частых вопросов и инструкции прямо в приложении
