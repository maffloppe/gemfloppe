# Gemfloppe

Клиент для Android: DNS и VPN для сервисов, которые не работают из России. Один экран для подключения, раздельный DNS по сервисам, автовыбор сервера.

Исходный код в этом репозитории не публикуется. Релизов пока нет.

## Что умеет

- **VPN-режим.** Туннель через выбранный сервер, все приложения в туннеле.
- **DNS-режим.** Меняется только DNS, остальной трафик идёт напрямую и не тормозит.
- **Раздельный DNS.** Выбранные сервисы идут через Smart DNS, остальное — через VPN. Список сервисов в приложении, 44 цели в категориях: нейросети, видео, соцсети, общение, музыка, игры, работа.
- **Обратный режим.** Через VPN идут только выбранные сайты, всё остальное напрямую.
- **Автовыбор сервера.** Подключение ко всем серверам подписки одним конфигом: балансировщик Xray сам держит трафик на живом сервере, переключение без разрыва.
- **Автовыбор DNS.** При подключении проверяется, подменяет ли резолвер адреса для выбранных сервисов, среди подходящих берётся самый быстрый.
- **Проверка DNS.** Если выбранный резолвер не работает для сервиса, выбранного для пинга, приложение предупреждает до подключения.
- **Протоколы DNS.** IPv4, DoH, DoT на каждый резолвер отдельно.
- **Пинг.** Пресеты по сервисам, свой URL, TCP-проверка перед замером.
- **Сторож сервера.** Если сервер перестал отвечать, приложение предлагает переключиться, но не делает это само.
- **Справка.** Десять частых вопросов и инструкции для Android и iPhone прямо в приложении.
